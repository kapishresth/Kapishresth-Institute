# Kapishresth Institute Website

A professional and modern website for Kapishresth Institute, featuring programs for Post 10th and Post 12th Graduation courses.

## Features

- 🎓 **Responsive Design** - Works perfectly on all devices (desktop, tablet, mobile)
- 🎨 **Modern UI** - Professional gradient color scheme with smooth animations
- 📚 **Course Information** - Details about Post 10th and Post 12th Graduation programs
- 👨‍🏫 **Faculty Section** - Information about experienced educators
- 📋 **Admissions** - Admission requirements and inquiry form
- 📞 **Contact Section** - Multiple ways to get in touch
- 🔗 **Social Media Links** - Connect on various platforms
- ⚡ **Fast & Optimized** - Pure HTML, CSS, and JavaScript (no dependencies)

## Sections

1. **Navigation Bar** - Sticky navigation with smooth scrolling
2. **Hero Section** - Eye-catching welcome message
3. **About Us** - Institute mission and key features
4. **Courses** - Detailed course cards
   - Post 10th Graduation (2-Year Program)
   - Post 12th Graduation (3-Year Program)
5. **Faculty** - Meet our experienced educators
6. **Admissions** - Requirements and inquiry form
7. **Contact** - Multiple contact options
8. **Footer** - Copyright and credits

## Customization

To customize the website, edit the following:

### Colors
Modify the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #1e3c72;      /* Primary blue */
    --secondary-color: #2a5298;    /* Secondary blue */
    --accent-color: #ff6b6b;       /* Red accent */
}
```

### Content
- Update institute details in the HTML file
- Add actual faculty member information
- Replace placeholder contact information
- Add real images and content

## Usage

1. Clone or download this repository
2. Open `index.html` in a web browser
3. Customize the content as needed
4. Deploy to a web server
